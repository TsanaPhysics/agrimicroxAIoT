## 📱 ระบบความจริงเสริม AR 3D ArUco Book (WebAR)

ตำราเล่มนี้ได้รับการออกแบบร่วมกับระบบความจริงเสริมบนเว็บ (WebAR) ทำงานร่วมกับรหัสมาร์กเกอร์ **ArUco (DICT_6X6_250)** เพื่อให้นักศึกษาสามารถใช้สมาร์ตโฟนเปิดกล้องส่องมาร์กเกอร์ที่ปรากฏในคู่มือปฏิบัติการ (บทที่ 11) เพื่อดูแบบจำลอง 3 มิติเสมือนจริง อุปกรณ์การทดลอง และโครงสร้างชีวโมเลกุลสามมิติได้ทันที 60 FPS

* **🌐 เปิดใช้งาน WebAR ทันทีบนมือถือ:** [คลิกเปิด WebAR 3D Interactive Lab](ar_3d_aruco_book/index.html)
* **📑 แผ่นการ์ดมาร์กเกอร์รวมสำหรับพิมพ์ A4:** [ดาวน์โหลด ar_markers_sheet_A4.pdf](ar_3d_aruco_book/ar_markers_sheet_A4.pdf)

### ตารางรหัสมาร์กเกอร์และแบบจำลอง 3 มิติ (8 ปฏิบัติการมาตรฐาน)

| ArUco ID | ปฏิบัติการทดลอง (บทที่ 11) | หน้า | แบบจำลอง 3 มิติเสมือนจริง | ชีวโมเลกุล PDB ที่เกี่ยวข้อง |
| :---: | :--- | :---: | :--- | :---: |
| **0** | ปฏิบัติการที่ 1: Winogradsky Column | 133 | คอลัมน์แก้ว 4 ชั้นนิเวศจุลินทรีย์ดิน ไล่ระดับ $O_2 / H_2S$ | - |
| **1** | ปฏิบัติการที่ 2: *Rhizobium* จากปมรากถั่ว | 134 | ปมรากถั่วผ่าซีก และการดักจับออกซิเจนด้วยเลกเฮโมโกลบิน | PDB: `1GDJ` (Leghemoglobin) |
| **2** | ปฏิบัติการที่ 3: จุลินทรีย์ละลายฟอสเฟต (PSI) | 135 | วุ้น Pikovskaya วงใส Clear Zone และเวอร์เนียคาลิปเปอร์ 3D | - |
| **3** | ปฏิบัติการที่ 4: ราปฏิปักษ์ *Trichoderma* (PIRG) | 136 | Dual Culture Confrontation Assay และกลไกเส้นใยพันรัด | PDB: `1CTN` (Chitinase) |
| **4** | ปฏิบัติการที่ 5: การตรวจเชื้อราไมคอร์ไรซา (AMF) | 137 | รากพืชย้อมสี Trypan Blue โครงสร้าง Arbuscules และกริดตาราง | - |
| **5** | ปฏิบัติการที่ 6: การวิเคราะห์คุณภาพปุ๋ยชีวภาพ | 138 | หลอดเจือจาง Serial Dilution ($10^{-1}$ ถึง $10^{-6}$) และ MacConkey | - |
| **6** | ปฏิบัติการที่ 7: การสกัด Soil Metagenomic DNA | 139 | หลอดบีดบีตติ้ง Spin Column เกลียวคู่ B-DNA และสเปกตรัม Nanodrop | PDB: `1BNA` (B-DNA Helix) |
| **7** | ปฏิบัติการที่ 8: PCR โรคพืช และการตรวจด้วย OpenCV | 140 | เครื่อง Mini PCR เจลเรืองแสง UV และกรอบประเมินพื้นที่โรค OpenCV | PDB: `1TAU` (Taq Polymerase) |
